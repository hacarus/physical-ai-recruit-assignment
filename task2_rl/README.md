# 課題 2: 強化学習

## 1. 概要

2 次元平面上の点を start から goal まで移動させるタスクについて、PPO (Proximal Policy Optimization) でエージェントを学習しました。
環境は 2 種類あり、それぞれの環境で学習したエージェントと、学習中の記録を用意しています。

あなたはこれらの学習済みエージェントを評価する担当者です。以下の前提をもとに、課題に取り組んでください。

## 2. 前提

### 2.1. 環境 (`env.py`)

環境は課題 1 と同じです。

| 項目 | 内容 |
| --- | --- |
| 平面 | x, y ともに `[-1, 1]` の正方形 |
| start | `(-0.75, y)`。`y` は `[-0.1, 0.1]` から一様に選ばれる。t = 0 で点は start にある |
| goal | `(0.75, y)`。`y` は `[-0.1, 0.1]` から一様に選ばれる。goal から距離 `0.1` 以内に入ると到達 |
| 観測 | 点の現在位置と goal の位置 `[x, y, goal_x, goal_y]` |
| 行動 | 2 次元の速度 `[vx, vy]` (連続値)。ノルムが上限 `0.6` を超える場合は `0.6` に縮められる |
| 時間刻み | 1 ステップあたり `Δt = 0.05`。位置は `p ← p + v Δt` で更新される |
| エピソードの上限 | 200 ステップ |

レイアウトは以下の 2 種類です。

- `straight`: 障害物がなく、真ん中付近をまっすぐ進めば goal に着く
- `wall`: 平面の中央に壁 (`-0.3 ≤ x ≤ 0.3`, `-0.6 ≤ y ≤ 0.6`) があり、迂回しないと goal に着けない

### 2.2. 報酬とエピソードの終了

| 事象 | 報酬 | エピソード |
| --- | --- | --- |
| 1 ステップごと | `-0.05` | 継続 |
| goal に到達 | `+1` (そのステップの `-0.05` に加算) | 終了 |
| 壁に衝突 | なし (そのステップの `-0.05` のみ) | 終了 |
| 外枠からはみ出す | なし | 終了しない。位置を枠内に押し戻す |
| 200 ステップ経過 | なし | 打ち切り |

`env.step()` は `(obs, reward, terminated, truncated, info)` を返します。

### 2.3. 与えられるもの

| ファイル | 内容 |
| --- | --- |
| `env.py` | 環境 |
| `ppo.py` | PPO の学習コード |
| `checkpoints/ppo_straight.pt` | `straight` 環境で学習したエージェント |
| `checkpoints/ppo_wall.pt` | `wall` 環境で学習したエージェント |
| `logs/straight.csv`, `logs/wall.csv` | 学習曲線のログ。学習中に終了したエピソードごとの報酬合計 (`episode`, `global_step`, `return`) |
| `plot_learning_curve.py` | 学習曲線を描画するスクリプト |
| `rollout_example.py` | 学習済みエージェントを読み込み、1 エピソード実行する例 |

エージェントは以下のコマンドで学習しました (CPU で数分程度)。

```bash
$ uv run python ppo.py --layout straight --out checkpoints/ppo_straight.pt --log logs/straight.csv
$ uv run python ppo.py --layout wall --out checkpoints/ppo_wall.pt --log logs/wall.csv
```

学習曲線は以下で描画できます。

```bash
$ uv run python plot_learning_curve.py logs/straight.csv logs/wall.csv --out outputs/learning_curve.png
```
